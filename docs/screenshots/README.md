# Screenshots

The main README shows these files. Take them in a dark terminal about 120x35,
crop to the terminal window, and save as PNG with exactly these names:

| File | What to show |
|---|---|
| `workspace.png` | The main app: file tree, a spirit working (its "writing ..." line), and the Crypt chat |
| `welcome.png` | The first-run welcome page with the ID card and "Kiro CLI" as the agent (`selecle onboard`) |
| `crypt.png` | A message to the Crypt and its reply raising a spirit |
| `multiplayer.png` | Two terminals side by side: the host and a friend who joined with `selecle join` |
| `replay.png` | `/feed` or `/replay`, the time machine of spirits' deeds |
| `settings.png` (optional) | `/settings` with a pixel avatar ID card |
